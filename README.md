# Проект: Консольное приложение «Симулятор банковского терминала» (C++)

Реализация учебного проекта по дисциплине «Объектно-ориентированное программирование с использованием языка C++».

## 📌 Описание проекта
Приложение представляет собой симулятор банковской системы управления счетами пользователей через консольный интерфейс. Программа позволяет создавать различные типы счетов, проводить по ним транзакции, а также поддерживает **долгосрочное хранение данных между запусками** благодаря встроенной системе сохранения в файл. Проект наглядно демонстрирует применение трех основных принципов ООП и правильное управление динамической памятью.

---

## 🚀 Весь реализованный функционал
*   **Автоматическая загрузка данных:** При старте программа ищет файл `accounts.txt` и восстанавливает сохраненные счета. Если файла нет, программа запускается с чистой базой.
*   **Создание счетов:** Возможность открывать сберегательные (под процент) и расчетные (с комиссией) счета.
*   **Пополнение баланса:** Безопасное внесение средств на счет с проверкой на корректность суммы.
*   **Снятие средств:** Списание денег с учетом специфики счета (проверка лимитов для сберегательного, автоматический расчет комиссии для текущего).
*   **Межбанковский перевод:** Прямой перевод средств между двумя любыми счетами в системе.
*   **Начисление процентов:** Массовое начисление годовых процентов на баланс всех сберегательных счетов в один клик.
*   **Общий отчет:** Вывод подробного структурированного списка всех существующих счетов.
*   **Автоматическое сохранение:** При выходе из программы (пункт меню `0`) все актуальные данные записываются в файл `accounts.txt`.
*   **Защита от некорректного ввода:** Встроенный механизм очистки буфера консоли (защита от случайного ввода букв вместо цифр в меню).

## 🛠 Демонстрация принципов ООП в коде

1.  **Инкапсуляция:** Все критические данные счетов (`accountNumber`, `ownerName`, `balance`) скрыты в секциях `private` и `protected`. Прямой доступ к ним извне заблокирован. Изменение баланса происходит строго через открытые (`public`) методы управления (`deposit`, `withdraw`), внутри которых стоит жесткая валидация транзакций.
2.  **Наследование:** Создан базовый абстрактный класс `Account`. От него публично наследуются два дочерних класса: `SavingsAccount` и `CheckingAccount`. Наследники автоматически перенимают базовые свойства, исключая дублирование кода.
3.  **Полиморфизм:** Используются виртуальные методы и чисто виртуальная функция снятия денег `virtual bool withdraw(...) = 0;`. Класс `Bank` управляет счетами через массив указателей базового типа `std::vector<Account*>`. При вызове методов снятия денег или вывода информации, C++ на лету определяет реальный тип объекта и вызывает нужную логику (с комиссией или без).

## 📂 Архитектура проекта (Структура файлов)
Код разделен на заголовочные файлы и файлы реализации в соответствии со стандартами разработки:
*   `Account.h` / `Account.cpp` — базовый абстрактный класс банковского счета.
*   `SavingsAccount.h` / `SavingsAccount.cpp` — класс сберегательного счета (с геттером ставки и начислением процентов).
*   `CheckingAccount.h` / `CheckingAccount.cpp` — класс расчетного счета (с геттером и логикой списания комиссии).
*   `Bank.h` / `Bank.cpp` — класс-менеджер. Хранит базу, выполняет транзакции и отвечает за работу с файловыми потоками (`std::ifstream`, `std::ofstream`).
*   `main.cpp` — точка входа, текстовое меню взаимодействия, фиксация окна перед закрытием.

## 💻 Инструкция по компиляции приложения (через g++)

Чтобы собрать полностью **автономный `.exe` файл**, который запустится на любом компьютере без требования сторонних библиотек (DLL), выполните следующие шаги:

1. Поместите все 9 файлов проекта в одну папку.
2. Откройте терминал в этой папке.
3. Скопируйте и запустите команду компиляции со статической линковкой:
   ```bash
   g++ -std=c++11 main.cpp Account.cpp SavingsAccount.cpp CheckingAccount.cpp Bank.cpp -static-libgcc -static-libstdc++ -Wl,-Bstatic,--whole-archive -lwinpthread -Wl,--no-whole-archive -o bank_system
   ```
4. В папке появится готовое приложение **`bank_system.exe`**.

### Запуск приложения:
*   Вы можете запустить программу прямо из терминала:
    ```bash
    .\bank_system.exe
    ```
*   Или запустить её двойным кликом мыши через проводник Windows как обычную программу. Окно не закроется автоматически при выходе — оно будет ждать нажатия клавиши `Enter`.
